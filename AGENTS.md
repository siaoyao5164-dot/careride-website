# AGENTS.md

CareRide is a single-page marketing and booking site for a private car transport and hospital accompaniment service in Penang, Malaysia. Built with TanStack Start (React 19), Tailwind CSS 4 and TypeScript, and deployed on Netlify. Bookings go to WhatsApp as a prefilled message (`wa.me`). Location search and road distance use free OpenStreetMap services (Photon + OSRM, no API key). Customer registration, vouchers, referrals, bookings and testimonials are stored in Netlify Database (Postgres via Drizzle); the private `/admin` dashboard uses Netlify Identity.

## Rules and decisions

- **Never hard-code prices or wording in components.** Prices come from `src/config/pricing.ts`, text from `src/i18n/translations.ts`. All three languages must keep identical keys (enforced by the `Translation` type).
- Transport fare per leg = max(RM25, road km × RM3.6), rounded to the nearest RM; round trip = 2 legs of the same distance. Distance is the OSRM driving distance between the exact pickup and destination coordinates.
- Do NOT show the per-km rate anywhere on the site. The estimate shows: transport fare, crossing surcharge (separate line, only when crossing), peak charge, accompaniment, subtotal, voucher balance, voucher discount, final amount. Crossings = number of legs when the two points are on different sides (`sideOf`, using `pricing.island`), else 0.
- Vouchers apply only to transport (distance fare + crossing + peak), never accompaniment; discount ≤ eligible fare; payable ≥ 0 (`applyVouchers`).
- Voucher lifecycle: available → reserved (when the customer taps Book via WhatsApp; server creates a booking) → redeemed (only when the admin marks the booking completed). Cancel releases it. Pending bookings older than `rewards.reservationHoldDays` auto-cancel. Opening WhatsApp never redeems anything.
- The server recalculates the price and checks every voucher rule; never trust amounts from the browser. Reservation uses a conditional UPDATE so a voucher can't be reserved twice.
- Welcome voucher: one per customer (partial unique index), only usable while first_ride_status = pending; it expires when the first ride is completed without it.
- Peak surcharge applies per leg based on the pickup time (outbound) and optional return pickup time (round trip). Windows: start included, end excluded.
- Accompaniment hours: minimum 2. It's charged once per booking, not per leg.
- If the distance lookup fails, the customer can still send the WhatsApp request; the message says the estimate is not available. Keep `pricing.test.ts` passing if you change the formula.
- Searches are limited to `pricing.serviceBounds` (roughly Penang state). The WhatsApp message includes each location's address and a Google Maps link.
- Booking never claims confirmation. The WhatsApp message follows the selected website language (owner request) and includes the booking reference and preferred language.
- SSR renders English (for SEO). The saved language is applied on the client in `useEffect` to avoid hydration mismatches.
- Do not add fake reviews, testimonials, ratings or claims. Testimonials come only from the `testimonials` table, entered by the owner in /admin. Don't add review/aggregateRating JSON-LD. JSON-LD must only include accurate business data (no street address or opening hours are known).
- If `siteUrl` changes, also update `public/robots.txt` and `public/sitemap.xml`.
- Use large touch targets (≥ 56px for form controls) and large text. The audience includes elderly users.
